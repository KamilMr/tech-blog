- Worked on using `gh` with two accounts, two repos, and SSH. I had to log in to the second account with `gh auth login --hostname github.com`, and then:

```bash
gh auth status
gh auth switch --hostname github.com --user USERNAME
```

The proper way was to create SSH aliases to select the right account:

```sshconfig
   Host github.com # that is my private account
       HostName github.com
       User git
       IdentityFile ~/.ssh/keys/id_rsa.github
       IdentitiesOnly yes

   Host github-sk1
       HostName github.com
       User git
       IdentityFile ~/.ssh/keys/sk1
       IdentitiesOnly yes

   Host bitbucket-sk2
       HostName bitbucket.org
       User git
       IdentityFile ~/.ssh/keys/sk2
       IdentitiesOnly yes
```

`ssh -T <host in ssh config>`
