> I used AI to improve my grammar and English phrasing.

- **Amplitude.** Today I came across [Amplitude](https://amplitude.com/), a platform that helps analyze how users interact with websites and applications. I plan to try it in one of my client's projects. I haven't explored it in much detail yet, but I also want to compare it with other tools available on the market.

- **Synchronizing the frontend with the backend.** At work, I was dealing with a problem related to keeping the UI in sync with what is actually happening on the backend. Our application communicates with a dock simulator and a Cesium simulator, which represent the drone dock and the drone itself. The drone sends a video stream through OvenMediaEngine to the frontend. Users can switch between different camera modes, such as thermal, zoom, and split view (thermal and zoom together). The tricky part is that commands travel asynchronously through the backend using MQTT. My task was to make sure the frontend reflects the actual state of the system, rather than simply assuming that a command has been executed because the user clicked a button.

- **Automating Git synchronization.** I often need to synchronize our repositories with branches maintained by another team. Since we have several related repositories, I created a skill for my coding agent, along with a few helper scripts, to automate part of this process. The skill prepares branches with the latest changes while trying to keep the process safe. It doesn't create PRs yet, and I still need to review the changes myself. But at least I no longer have to repeat all the preparation steps manually every day or two.

- **Understanding the backend with AI agents and Vim.** I also spent some time trying to understand our backend better. I picked two specific flows and asked the agents to map out how things move through the system, with short comments and references to the relevant files. Then I opened the results in Vim and used `gF` to jump directly to the referenced files and lines. Instead of relying only on the agents' explanations, I could read the actual code and understand it myself. I also wrote down a few keywords on paper to help me remember what I had learned.
