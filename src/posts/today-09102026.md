- I spent 25 minutes doing kata—I practiced kubectl commands today.
	scale — changes the desired number of Pod replicas.
	`kubectl scale deployment web --replicas=3`
	
	describe — shows detailed information about a resource.
	`kubectl describe service web`
	
	run — creates a Pod, often for temporary testing.
	`kubectl run test-client --image=curlimages/curl --restart=Never --rm -i -- curl http://web`
	
	expose — creates a Service from an existing workload.
	`kubectl expose deployment web --port=80 --type=ClusterIP`
	
	get — lists resources and their current status.
	`kubectl get pods`
	
	port-forward — temporarily forwards a local port to a Kubernetes resource.
	`kubectl port-forward deployment/web 8080:80`
