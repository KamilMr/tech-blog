- Most of my time at work was spent creating an infrastructure repository that would allow my team to use a Dockerfile and a couple of Bash scripts to bootstrap and set up everything needed to run the project. This includes the frontend, the SSO frontend, and the backends. It also includes the in-flight server, dock simulator, Cesium simulator, and MQTT messaging, which allow the services to communicate with each other. That task took me many hours of writing, thinking, and fixing bugs. I am happy with the solution. The most interesting part was putting a couple of files behind a password-protected Nginx server. The server protects those files and allows my team to download them via `curl` over HTTPS. The next step will probably be to protect those important files with SOPS, using age to encrypt them.
